# Portfolio

Sitio estático en [Astro](https://astro.build), en español (`/`) e inglés (`/en/`).

```bash
npm install
npm run dev      # desarrollo en http://localhost:4321
npm run build    # genera el sitio en dist/
```

Todo el texto está en `src/data/es.ts` y `src/data/en.ts`; los enlaces de contacto, en `src/data/types.ts`.
